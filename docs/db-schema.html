Два триггера

Денормализованные счётчики не трогает код — их поддерживает PostgreSQL при каждой вставке или удалении строки. Никакой рассинхронизации между «сырыми» строками и агрегатами.

update_poll_slot_votes_count

Держит актуальным число голосов у каждого слота — чтобы выбор победителя был одним ORDER BY votes_count, без подсчёта poll_votes на каждый запрос.

poll_votes — INSERT / DELETE → poll_slots.votes_count = COUNT(*)

update_meeting_participants_count

Считает участников встречи по посещаемости: только строки со статусом present попадают в счётчик.

attendance — INSERT / UPDATE OF status → meeting_instances.participants_count
