# Check-in с счётчиком отметившихся

Дата: 2026-08-24

## Цель

Карточка check-in обновляется на месте со счётчиком отметившихся, вместо
сообщения «Ты на встрече» в чат. Окно отметки — только во время встречи + 15 мин после.

## Окно check-in

- Открывается в `scheduled_start`, закрывается в `scheduled_end + 15 мин`.
- Длительность встречи — `config["meeting_duration_minutes"]` (default 60).
- До начала встречи — отметка не засчитывается, карточка не шлётся.

## Карточка

```
Встреча началась? 🎉

Отметились: N

[Я на встрече ✅]
```

- Карточка приходит в момент начала (`scheduled_start`), а не за 15 мин до.

## Поведение

- Клик внутри окна → `attendance` (present) → карточка обновляется на месте
  (`updateMessageAction`) с новым счётчиком. Текста в чат нет.
- Клик вне окна (до начала / после конца+15) → ничего не показываем (пустой ответ),
  счётчик не растёт.

## Что меняется

| Файл | Изменение |
|------|-----------|
| `app/services/checkin.py` | `checkin_window(start, end, after_min)`; `build_checkin_card` со счётчиком; `submit_checkin` возвращает count |
| `app/services/invites.py` | джоб открытия в `scheduled_start`, закрытия в `scheduled_end + 15` |
| `app/api/google_chat.py` | клик check-in → `updateMessageAction` (или пустой ответ вне окна) |

## Вне скоупа

- Напоминание о встрече (T−1ч) — не трогаем.
