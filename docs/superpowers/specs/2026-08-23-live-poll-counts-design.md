# Голосование с живыми счётчиками (ежедневный опрос)

Дата: 2026-08-23

## Проблема

Сейчас на каждый клик по кнопке времени бот отвечает отдельным сообщением
«Спасибо, учёл! 🙌». При 10+ участниках чат засоряется десятками подтверждений.

## Решение

Карточка опроса **обновляется на месте** (`updateMessageAction`), показывая
актуальные счётчики голосов, вместо нового сообщения на каждый клик.

## Карточка

```
Кто сегодня и во сколько? 🗓️

15:00 — 4
16:00 — 2
17:00 — 1
Не могу — 0

[15:00] [16:00] [17:00] [Не могу]
```

- При создании опроса все счётчики — нули.
- Персонального «твой выбор» нет (карточка общая на группу) — согласовано.

## Поведение

1. Клик по кнопке → голос сохраняется (`submit_poll`, переголос «одно время
   на человека» уже реализован).
2. Бот читает свежие счётчики (`poll_slots.votes_count` + число `not_available`)
   и возвращает `updateMessageAction` с перерисованной карточкой.
3. Никаких сообщений в чат.
4. После дедлайна клик → «Голосование уже закрыто», карточка не обновляется.

## Что меняется в коде

| Файл | Изменение |
|------|-----------|
| `app/services/weekly_poll.py` | `build_daily_poll_card` — добавить секцию счётчиков; новая функция перерисовки карточки с актуальными counts |
| `app/api/google_chat.py` | `_submit_daily_poll` — возвращать `updateMessageAction` вместо текста «спасибо»; читать `message.name` из события клика |
| `app/scheduler.py`, `scripts/send_poll_now.py` | без изменений (карточка уже с нулями) |

## Что НЕ меняется

- Финализация (14:05), структура БД (`poll_votes`/`poll_responses`/`poll_slots.votes_count`),
  переголос, сабмит после дедлайна.

## Нюанс

`message.name` (id сообщения с карточкой) приходит в событии клика — отдельно
сохранять не нужно. Формат ответа — add-on (`hostAppDataAction.chatDataAction`),
обновление через `updateMessageAction`.
