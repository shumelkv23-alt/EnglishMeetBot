# Активности — Этап D: Шпион

Дата: 2026-08-24

## Цель

Игра на маскировку: все, кроме шпиона, получают в личку рандомное английское слово
(по теме), шпион — ничего. Участники в группе обсуждают слово, шпион пытается
не спалиться. В конце голосование, кто шпион.

## Слова (захардкожены по темам)

```python
WORD_BANK = {
    "food":     ["pizza", "sushi", "pancake", "popcorn", "sandwich"],
    "animals":  ["penguin", "kangaroo", "octopus", "hamster", "flamingo"],
    "objects":  ["umbrella", "backpack", "toothbrush", "microwave", "scooter"],
    "places":   ["airport", "beach", "library", "gym", "cinema"],
}
```

## Механика

1. `/spy` → бот спрашивает «сколько игроков» и просит отметиться (Этап A).
2. Бот выбирает тему + слово + тайно назначает шпиона (рандом).
3. Каждому игроку в личку: не-шпионам — слово; шпиону — «Ты шпион 🤫» (+ тема).
4. Участники в группе обсуждают слово (по очереди задают вопросы/описывают).
5. Ведущий (или бот) запускает голосование «кто шпион» — кнопки с именами.
6. Подсчёт: команда угадала шпиона → команде +1; шпион угадал слово (или его не
   вычислили) → шпиону +3. Очки в `leaderboard_ledger`.

## Состояние сессии

```python
{
  "players": [user_id, ...],
  "topic": str,
  "word": str,
  "spy": user_id,
  "votes": {voter: user_id},   # кого считают шпионом
}
```

## Модули

- `app/services/games/spy.py` — банк слов, назначение шпиона, карточка голосования, подсчёт.

## Интерфейсы

- `WORD_BANK: dict[str, list[str]]`
- `assign_roles(players) -> dict` (word, topic, spy)
- `build_spy_vote_card(players, action_url) -> dict`
- `score_spy(session, votes) -> dict` (очки)

## Вне скоупа

- Таймер раунда, авто-очередность вопросов — обсуждают люди, бот только раздаёт и голосует.
