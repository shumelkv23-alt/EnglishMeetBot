## Как это работает (кратко)

1. **Вс, 10:00** — создаётся опрос недели: по 1 слоту на день (Пн–Вс, 13:00), карточка уходит всем.
2. **Неделя** — люди выбирают дни (можно несколько) + отвечают на 2 вопроса по темам.
3. **Ежедневно в 20:00** — смотрим на ЗАВТРА:
   - набрал ≥ 3 голосующих → фиксируем встречу (час = максимум голосов, ничья → раньше), шлём анонс «завтра встреча», опрос закрыт;
   - не набрал → эскалация организатору (DM), опрос остаётся открытым;
   - за неделю ни один день не набрал кворум → опрос cancelled, финальная эскалация.
4. **Сообщения** появляются ТОЛЬКО после фиксации: анонс за день до встречи + напоминание за 1 час (конфиг `meeting_reminder_hours`).в
## Куда пишутся данные (таблицы и поля)

- **`weekly_polls`** — 1 строка на неделю: `week_start`, `voting_deadline` (вс 23:59), `status` (`active` → `closed`/`cancelled`).
- **`poll_slots`** — из `build_week_slots()`: `poll_id`, `slot_start`/`slot_end` (UTC), `location` (из `config.default_location`), `priority=0`, `votes_count=0`. **Перезапись:** при создании нового опроса недели — удалить старые слоты/голоса этого `poll_id` и вставить свежие.
- **`poll_responses`** — на голосующего: `profile_id`, `poll_id`, `status='responded'`, `responded_at`.
- **`poll_votes`** — на каждый выбранный день: `poll_response_id`, `profile_id`, `poll_slot_id`, `voted_at`. Счётчики `votes_count` пересчитают триггеры БД.
- **`answers`** — ответы на 2 вопроса по темам: `profile_id`, `question_text`, `answer_text`, `week_start`, `is_public`.
- **`meeting_instances`** — при фиксации: `poll_id`, `selected_slot_id`, `scheduled_start`/`scheduled_end`, `location`, `status='scheduled'`, `activity_type` (по темам, правило потом).
- **`attendance`** — НЕ трогаем (создаётся при чек-ине, констрейнты не позволяют пустую pending-запись).

## Как подключить в бота (3 шага)

1. **Вебхук** (`app/api/google_chat.py`): на клик кнопки `submit_poll_vote` — распарсить `formInputs` (дни + темы), сохранить в `poll_responses`/`poll_votes`/`answers` (см. карту выше), ответить «спасибо».
2. **Создание опроса**: в воскресенье вызвать `build_week_slots()` → создать `weekly_polls` + `poll_slots` (перезапись), разослать `build_poll_card()` через `chat_sender`.
3. **Планировщик** (APScheduler в lifespan): ежедневно в 20:00 — `decide_for_tomorrow()` по завтрашнему дню; если `MEETING` → `plan_week_messages()` → отправить анонс/напоминание по расписанию. `process_next_*`-логику собирается из функций модуля.
