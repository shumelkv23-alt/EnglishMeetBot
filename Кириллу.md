## Как это работает (кратко)

1. **Пн–Пт 9:00** — опрос на сегодня: «Сможешь сегодня прийти?» [Да/Нет] в личку всем.
2. **До 13:00** — «Да» → выбор **одного** времени (15–16 / 16–17 / 17–18). Переголосовать можно.
3. **13:00** — финализация: слот с ≥ 4 голосов → встреча. В группу — анонс
   (время + место + активность/тема), напоминание за 1 час. Кворума нет → тишина.
4. **18:00** — чек-ин «Ты был(а) на встрече?» в личку участникам; ответ → `attendance`.
   **Баллы не трогаем** — только факт присутствия.

## Куда вставить твою логику (активность и тема)

Файл `app/services/activity.py`:

```python
# TODO(Кирилл): тут выбираем активность и тему встречи.
async def pick_activity(db, meeting) -> str | None:
    ...
```

`meeting` — объект `MeetingInstance` (слот, набравший кворум; есть `scheduled_start`,
`location`, `poll_id`, `selected_slot_id`). Верни строку (или `None`, тогда в анонсе
будет «активность и тема уточняются»). Если хочешь сохранять данные — пиши в
`meeting.activity_type` / `meeting.activity_data` (JSON), они уже есть в модели.

`pick_activity` вызывается из `finalize_today` (в `poll_store.py`) перед отправкой
анонса — подключать больше ничего не нужно, просто реализуй функцию.

## Куда пишутся данные (таблицы и поля)

- **`weekly_polls`** — 1 строка на день: `week_start` = дата дня, `voting_deadline` = 13:00, `status` (`active` → `closed`).
- **`poll_slots`** — 3 слота на день из `build_daily_slots()`: `slot_start`/`slot_end` (UTC), `location`, `priority=0`, `votes_count=0`.
- **`poll_responses`** — ответ «да/нет»: `profile_id`, `poll_id`, `status='responded'`, `responded_at`, **`will_attend BOOLEAN`** (новый столбец).
- **`poll_votes`** — 1 голос на участника за выбранный слот: `poll_response_id`, `profile_id`, `poll_slot_id`, `voted_at`. Перезапись при переголосовании. Счётчики `votes_count` пересчитывают триггеры БД.
- **`meeting_instances`** — при финализации: `poll_id`, `selected_slot_id`, `scheduled_start`/`scheduled_end`, `location`, `status='scheduled'`, `activity_type`/`activity_data` (сюда твоя активность/тема).
- **`attendance`** — чек-ин: `source='self_checkin'`, `status` `present`/`absent`, `checkin_attempted_at`, `is_within_window=True`. Триггер обновит `participants_count` встречи.
- **`leaderboard_ledger`** — **НЕ трогаем** (баллы — позже, отдельной задачей).

## Как подключить в бота

Уже подключено — тебе осталась только `pick_activity`. Остальное (создание опроса,
приём голосов, финализация, чек-ин) реализовано в `poll_store.py` / `scheduler.py` /
`app/api/google_chat.py`. Если будешь менять сигнатуру `pick_activity`, обнови вызов
в `poll_store.finalize_today` и `build_announcement_text` в `poll_logic.py`.
